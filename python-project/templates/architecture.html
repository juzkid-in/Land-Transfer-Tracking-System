Working of the System (12 Academic Steps)
Step 1: System initializes by constructing the Genesis Block (Block 0).
Step 2: Genesis Block previous hash is mathematically set to "0".
Step 3: Administrator inputs land parcel details (Land ID, survey no, owners).
Step 4: The application packages input parameters into a transaction object.
Step 5: Transaction payload is placed into a new block candidate with index N.
Step 6: Block queries the latest block in memory and captures its SHA-256 hash.
Step 7: SHA-256 cryptographic function computes the unique block hash.
Step 8: Newly forged block is appended onto the blockchain list.
Step 9: Subsequent land transfers create blocks linked in an unbroken chain.
Step 10: Verification engine scans each block and recalculates hashes.
Step 11: If all recalculated hashes match, status is confirmed VALID.
Step 12: If any stored field is tampered with, validation flags INVALID.
