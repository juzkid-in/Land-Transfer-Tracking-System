What is a Genesis Block?

The Genesis Block is the very first block of a blockchain network. It serves as the immutable root of trust and common ancestor for all subsequent blocks. In this project, Block 0 initializes the land transfer ledger.

Why is Previous Hash set to "0"?

Because the Genesis Block is the first block in the blockchain, it has no preceding block. To satisfy the data structure requirement of having a previous_hash field, it is conventionally hardcoded to "0" or a string of zeroes.

How are Subsequent Blocks Linked?

Block 1 takes the exact SHA-256 hash of Block 0 as its previous_hash. Block 2 takes the hash of Block 1, creating an unbroken cryptographic linked list back to the Genesis Block.

Why is SHA-256 Hashing Important?

SHA-256 is a one-way cryptographic hash function. Changing even a single character in a block (e.g. changing an owner's name) produces an entirely different 256-bit hash (the avalanche effect), exposing unauthorized modifications instantly during validation.
